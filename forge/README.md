# forge/

Owner: Laksh. The living specification, work orders, and the recovered rules.

Contents, once Forge has run:

- `rules.json` - `Rule[]`, exported from Forge's Modernize Legacy Code workflow
  run against Bryan's legacy fixture. Not hand-written. The whole pitch is that
  nobody wrote REQ-014 down and Forge recovered it from the code, so a
  hand-authored rules file would be the one thing that loses the room in Q&A.
- `prd.md`, `architecture.md`, `security-requirements.md`, `work-orders/` -
  generated by Forge from the mission, not prompted for directly.
- `mission.md` - the Forge mission link, shown on stage.

`rules.json` is the sanctioned fallback if the live Forge export fails during
the demo. It is still Forge output, just committed earlier.
